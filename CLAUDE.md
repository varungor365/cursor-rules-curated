# cursor-rules-curated - AI Agent Guidelines

If you are an AI assistant helping a user manage this repository, your job is to help them format new rules perfectly.

## Standards for New Rules
If a user asks you to add a new rule file to the `rules/` directory, ensure:
1. It uses markdown format.
2. It has a clear `h1` title (e.g. `# Vue & Nuxt Rules`).
3. The rules are opinionated (e.g. recommend a specific linter, framework, or CSS library).
4. Do not make the rules too long. 5-7 bullet points of the most critical architectural constraints are best.
